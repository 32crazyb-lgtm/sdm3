SDM Secondary School, Ujire - Complete Website Source

GET STARTED
Extract the ZIP and open index.html in your browser.
No installation or build step is needed.

FILES
Eight HTML pages; shared styles.css, fonts.css and script.js; assets folder containing photographs and local fonts.

EDITING
Edit HTML files to change page content. Edit styles.css for layout, colours and typography. Edit script.js for the mobile menu and faculty search. Keep the assets folder beside the HTML files.

HOSTING
Upload the contents of this folder to your web hosting public directory, keeping the folder structure intact.

CONTENT STATUS
The school name is SDM Secondary School, Ujire. Photographs, faculty, admission information and contact details still come from the Dharmasthala reference website and need Ujire-specific verification or replacement. Some news and programme links lead to that reference site.

FUNCTIONALITY
This is a static frontend. Telephone and email links open visitors' apps. No backend, lead database, CMS or submission form is included.

VALIDATION
Internal links, asset references and JavaScript syntax were checked. Visual browser testing was unavailable.
